# Laminari Launcher

Новый независимый Minecraft-лаунчер Laminari.

## Стек

- Tauri 2
- Vanilla JavaScript
- HTML / CSS
- Rust backend
- Minecraft будет запускаться отдельным процессом Java

## Текущий этап

Первая версия содержит новый чёрно-белый интерфейс Laminari, навигацию, связь JavaScript ↔ Rust и основу для будущего импорта Minecraft-сборок.

## Локальный запуск

1. Установить Node.js, Rust и системные зависимости Tauri 2.
2. Выполнить `npm install`.
3. Выполнить `npm run dev`.

## Сборка

`npm run build`

Windows-сборка также проверяется через GitHub Actions.
